SignDocs에서 평면 PDF나 스캔한 페이지에 새 텍스트를 추가하고 별도의 완성된 PDF 사본을 저장할 수 있습니다. 필요한 공간에 여러 줄 답변을 놓고 줄바꿈과 넘침을 확인하세요. 이것은 페이지에 이미 있는 글자를 고치거나 지우는 작업이 아닙니다. iOS 26의 Apple 미리보기도 텍스트 상자를 추가할 수 있으므로 필요한 작업을 해결할 수 있다면 다른 앱을 설치하지 않아도 됩니다.

## 먼저 페이지를 살펴보세요

선택 가능한 입력 필드가 있는 문서와 선만 인쇄된 문서는 다릅니다. 실제 필드가 있다면 지원되는 필드에 답변을 입력할 수 있습니다. 평면 페이지나 스캔에는 텍스트와 체크 표시를 직접 배치합니다. 눈에 보이는 사각형만으로 입력 필드가 있다고 판단하지 마세요. 기존 인쇄 내용이 틀렸다면 새 답변으로 가리지 말고 올바른 원본을 요청하세요.

## 텍스트를 넣는 순서

1. PDF가 클라우드에만 있다면 연결된 동안 먼저 내려받으세요. SignDocs에서 파일 앱의 PDF를 열고 제목과 전체 페이지 수를 확인합니다.
2. 답변을 넣을 페이지를 선택합니다. 주변 질문과 빈 공간을 읽고 어느 부분에 답해야 하는지 확인하세요.
3. 새 텍스트를 추가하고 필요한 답변을 입력합니다. 여러 줄이라면 문장이 끝까지 포함되어 있는지 확인하세요.
4. 텍스트의 위치와 크기를 조정합니다. 인쇄된 질문이나 옆 칸을 가리지 않도록 하고 마지막 줄의 끝까지 읽어 보세요.
5. 체크 표시가 필요한 평면 양식이라면 해당 빈칸에 직접 추가합니다. 표시와 질문이 정확히 연결되는지 확인하세요.
6. 모든 페이지를 검토하고 별도의 평면화된 PDF 사본을 저장합니다. Recent Docs에서 결과를 다시 열어 실제 출력의 글자를 확인하세요.

## 두 줄 답변 확인 예시

워크숍 신청서의 준비물 요청란에 두 문장을 입력한다고 가정하세요. 첫 문장만 확인하지 말고 두 번째 문장의 마지막 단어까지 읽으세요. 화면을 확대하면 보이더라도 최종 크기에서는 너무 작을 수 있습니다. 글자를 무작정 줄이기 전에 답변을 더 간결하게 쓸 수 있는지 검토하세요. 내용을 줄였다면 필요한 의미가 사라지지 않았는지도 다시 읽어야 합니다.

체크 표시는 옆 항목과 혼동되지 않도록 살펴보세요. 첫 번째 칸에 표시했다고 생각해도 두 칸 사이에 걸쳐 있으면 선택이 모호해집니다. 페이지 전체 보기와 읽기 쉬운 확대 보기에서 각각 검토하면 줄의 위치와 답변 내용을 함께 확인할 수 있습니다. 필요한 서명이 있다면 텍스트와 서명도 서로 겹치지 않아야 합니다.

## 대안과 저장 시 주의점

iOS 26 미리보기에서 PDF를 열고 양식을 직접 채울 수 없다면 Apple 설명에 따라 텍스트 상자를 추가할 수 있습니다. SignDocs는 종이에서 손글씨를 캡처해 답변과 함께 재사용하려는 경우에도 유용합니다. 기존 페이지 텍스트를 인식하는 OCR이나 자동 필드 감지 기능으로 이해하지 마세요. 추가한 텍스트는 새 대화형 필드를 만드는 기능도 아닙니다.

SignDocs에는 iOS/iPadOS 26 이상이 필요하며 무료 내보내기는 제한됩니다. 완성된 사본은 평면화되므로 내보낸 글자를 나중에 입력 필드처럼 편집할 수 있다고 기대하지 마세요. 빈 원본은 따로 보관하세요. 처리는 기기에서 이루어지며 처리용 문서 업로드나 계정이 필요하지 않습니다. 설치, 구매와 복원, 클라우드 파일 가져오기 및 외부 공유에는 별도의 연결 조건이 있습니다.
