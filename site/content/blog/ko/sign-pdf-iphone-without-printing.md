iPhone에서는 인쇄하지 않고 PDF에 서명할 수 있습니다. 파일을 열고 서명을 추가한 다음 올바른 페이지에 놓고 서명된 사본을 저장하세요. Apple 미리보기도 PDF 양식 서명을 지원합니다. 평소 종이에 쓰는 서명을 사용하려면 Signature Scan: Sign PDFs, 즉 SignDocs로 촬영해 종이 배경을 제거하고 PDF에 배치할 수 있습니다.

이 SignDocs 과정은 iOS 26 또는 iPadOS 26 이상이 필요합니다. 손글씨 서명의 이미지를 추가하며 신원 확인이나 인증서 기반 디지털 서명을 제공하지는 않습니다.

## 시작 전 준비

파일 앱에서 열 수 있는 위치에 PDF를 저장하세요. 이메일 첨부라면 먼저 다운로드합니다. 서명할 페이지와 수신자가 요구하는 다른 입력 사항을 확인하세요. 필요한 내용은 별도 도구로 채워야 하며 PDF에 서명한다고 양식이 자동으로 완성되지는 않습니다.

SignDocs에 저장한 서명 또는 새 서명을 캡처할 깨끗한 종이와 펜도 준비합니다.

## SignDocs에서 손글씨로 서명

1. 파일 앱에서 기존 PDF를 여는 옵션을 선택합니다.
2. 문서를 선택하고 제목과 페이지 수를 확인해 잘못된 버전에 서명하지 않도록 합니다.
3. 저장한 서명을 선택하거나 종이에서 캡처합니다. 새 서명은 카메라 가이드에 맞춰 촬영하고 자른 뒤 Clean, Balanced, Bold를 비교합니다.
4. 서명란이 있는 PDF 페이지를 선택합니다.
5. 서명을 선 위로 드래그하고 핀치로 크기를 맞춰 주변 글씨를 가리지 않게 합니다.
6. 읽기 좋은 크기로 페이지를 검토한 뒤 **Save File**로 새 서명된 PDF를 만듭니다.
7. 저장한 사본을 열고 전송 전에 서명을 확인합니다.

![Save File 버튼 위의 PDF에 놓인 손글씨 서명.](/mockup/place-signature.png)

촬영은 [손글씨 서명 스캔 가이드](/blog/scan-handwritten-signature-iphone/)를 참고하세요. 손가락으로 다른 형태를 그리는 대신 실제 잉크의 획을 보존하는 방법입니다.

## Apple의 기본 기능 사용

PDF에 이름, 날짜, 다른 답변도 필요하다면 해당 항목을 채우세요. 서명 이미지는 나머지 양식을 완성하지 않습니다. iOS 26의 미리보기에는 양식 입력과 서명 도구가 있으므로 필요를 충족하면 거기서 끝낼 수 있습니다.

### 미리보기에서 텍스트 필드 입력

1. PDF 양식을 미리보기로 엽니다. 원본을 남기려면 편집 전 파일명 옆 동작 메뉴에서 **복제**를 선택합니다.
2. **양식 채우기** 컨트롤을 선택합니다.
3. 필드를 선택해 정보를 입력합니다. 자동 완성 제안은 보내려던 정확한 내용인지 확인한 뒤 사용합니다.
4. 텍스트 상자나 서명이 필요하면 **추가**를 사용합니다. 연결한 Apple의 iOS 26 설명에서 컨트롤을 확인하세요.

각 필수 입력을 읽기 좋은 크기로 확인하세요. 한 칸에 이름을 입력해도 별도 서명란은 채워지지 않고 서명을 놓아도 빈 텍스트 필드는 완성되지 않습니다.

### 서명 단계를 고르기 전에 저장

미리보기의 뒤로 가기는 파일을 저장하고 메인 메뉴로 돌아갑니다. 파일명 옆 동작 메뉴에서 이름도 바꿀 수 있습니다. 작업용 사본을 빈 원본과 구별할 수 있게 이름을 붙이세요.

종이에서 가져온 서명을 사용하려면 작성한 PDF를 파일 앱을 통해 SignDocs로 열고 입력한 글씨가 보이는지 확인한 뒤 저장한 서명을 배치합니다. 위 SignDocs 과정은 서명 이미지에 관한 것으로 PDF 필드 편집 안내가 아닙니다. 필요한 글씨가 빠져 있다면 다시 양식을 채운 후 서명된 사본을 만드세요.

미리보기에서 추가한 서명으로 수신자의 조건을 충족한다면 파일을 검토하고 공유하면 됩니다. 다른 앱에서 두 번째 서명을 넣을 필요는 없습니다. 메뉴 위치는 OS에 따라 달라질 수 있으니 해당 버전의 Apple 안내를 함께 확인하세요.

## 최종 PDF 확인

편집 화면이 아닌 내보낸 파일을 검토하세요. 서명의 크기, 페이지 위치와 가독성을 보고 필요한 페이지가 빠지지 않았는지, 저장 후 다시 열리는지 확인합니다.

SignDocs는 원본을 보존하고 별도 서명된 사본을 저장합니다. 원본을 잘못 첨부하지 않도록 결과에 명확한 이름을 붙이세요. [저장 및 공유 가이드](/blog/save-share-signed-pdf-iphone/)가 마지막 단계를 설명합니다.

## 인증서 기반 서명이 필요하다면

손글씨 이미지와 인증서 기반 디지털 서명은 다릅니다. 수신자나 포털이 인증서, 신원 확인 또는 특정 서비스를 요구하면 지정된 절차를 따르세요. 이미지 하나를 넣으면 요건을 충족한다고 가정하지 마세요.

손글씨 서명 이미지를 받는 일상적인 문서라면 전체 문서를 인쇄하고 다시 스캔할 필요 없이 원본 PDF에서 작업해 별도 서명 사본을 만들 수 있습니다.
