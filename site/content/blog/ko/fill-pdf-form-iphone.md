SignDocs에서 지원되는 PDF 양식을 열고 기존 입력 필드에 답변을 넣은 뒤 별도의 평면화된 PDF 사본으로 저장할 수 있습니다. 텍스트, 체크박스, 라디오 버튼과 선택 목록을 각각 확인하세요. iOS 26의 Apple 미리보기도 양식 작성과 서명을 지원하므로 필요한 작업을 해결할 수 있다면 추가 설치는 필요하지 않습니다.

## 실제 입력 필드인지 확인하세요

대화형 양식은 선택할 수 있는 필드를 포함합니다. 스캔한 페이지나 평면 PDF에 인쇄된 사각형은 똑같아 보여도 입력 필드가 아닐 수 있습니다. SignDocs는 지원되는 표준 필드를 채우며 기존 위치를 유지합니다. 읽기 전용 필드는 계속 읽기 전용입니다. 입력되지 않는다고 인쇄된 질문 위에 답변을 덮어쓰지 마세요.

## 양식 작성 순서

1. 클라우드에만 있는 파일은 연결된 동안 내려받으세요. 파일 앱에서 SignDocs로 열고 문서 이름과 페이지 수를 확인합니다.
2. 선택 가능한 텍스트 필드를 눌러 답변을 입력합니다. 이름 철자와 끝 글자가 모두 보이는지 살펴보세요.
3. 체크박스는 질문을 읽고 표시합니다. 라디오 버튼과 선택 목록은 의도한 항목이 선택되었는지 별도로 검토합니다.
4. 읽기 전용 항목이 잘못되어 있다면 올바른 원본을 요청하세요. 필드를 옮기거나 제한을 해제하는 작업으로 이해하지 마세요.
5. 서명이 필요하면 손글씨를 선택하고 답변과 겹치지 않게 배치하고 크기를 조정합니다.
6. 모든 페이지를 읽고 완성된 별도 사본을 저장합니다. Recent Docs에서 다시 열어 실제 출력 내용을 확인한 후 공유합니다.

## 선택 항목을 교차 확인하는 예

워크숍 신청서에서 참가자 이름, 오전 또는 오후 세션, 준비물 요청을 각각 확인하세요. 이름이 정확해도 세션이 틀리면 신청 내용이 달라집니다. 목록을 선택한 뒤 옆 질문과 결과를 다시 읽고, 다른 페이지에 같은 질문이 있다면 답변이 의도대로 일치하는지도 확인하세요. 제출할 파일에 필요한 답변이 모두 있는지 페이지별로 검토합니다.

평면 페이지라면 [새 텍스트와 체크 표시 배치 안내](/ko/blog/add-text-flat-pdf-iphone/)를 따르세요. 글자를 수동으로 추가해도 기존 글자를 변경하거나 새로운 대화형 필드를 만드는 것은 아닙니다. 여러 줄 답변은 마지막 줄과 넘침을 확인해야 합니다.

## 저장과 대안

iOS 26 Apple 미리보기에서는 PDF를 열고 Form Filling을 선택한 다음 필드를 선택하여 키보드로 입력합니다. 직접 채울 수 없을 때 텍스트 상자를 추가하는 방법도 Apple이 설명합니다. SignDocs는 [종이의 손글씨를 캡처해](/ko/blog/scan-handwritten-signature-iphone/) 양식과 함께 쓰려는 경우 유용합니다.

SignDocs에는 iOS/iPadOS 26 이상이 필요하고 무료 내보내기는 제한됩니다. 결과는 평면화된 PDF이므로 내보낸 필드가 계속 대화형이라고 기대하지 마세요. 원본은 변경되지 않으며 다음 작성을 위해 보관하세요. 처리는 기기 안에서 이루어지고 처리용 업로드나 계정은 필요하지 않습니다. 설치, 구매와 복원, 클라우드 파일 가져오기 및 외부 공유에는 별도 연결 조건이 있습니다.
