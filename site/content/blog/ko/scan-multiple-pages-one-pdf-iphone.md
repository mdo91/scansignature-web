iPhone에서 여러 페이지를 하나의 PDF로 스캔하려면 최종 문서를 만들거나 저장하기 전에 페이지를 계속 추가하세요. SignDocs에서는 한 페이지를 촬영한 뒤 **Scan More**로 나머지를 추가하고 모두 준비되면 **Create PDF**를 선택합니다. 서명하거나 공유하기 전 페이지를 검토하세요.

Apple 메모의 스캐너도 저장 전에 추가 촬영을 지원합니다. SignDocs는 다음 단계로 손글씨 서명을 캡처해 스캔한 PDF에 놓으려는 경우 유용합니다. iOS 26 또는 iPadOS 26 이상이 필요합니다.

## 스캔할 종이 준비

페이지를 원하는 순서로 놓고 접힌 모서리를 펴세요. 종이 테두리가 잘 보이도록 대비가 있는 바닥을 선택합니다. 빛을 고르게 하고 페이지 영역에 손가락을 넣지 마세요.

먼저 종이 장수를 세고 뒷면에도 글씨가 있는지 확인합니다. 촬영하지 않은 뒷면은 스캐너가 포함할 수 없습니다. 빈 뒷면이나 첨부 페이지까지 필요한지, 내용이 있는 면만 필요한지 정하세요.

## SignDocs에서 페이지 스캔

1. 문서 스캔 기능을 엽니다.
2. 첫 페이지를 자동으로 촬영하거나 직접 시점을 고르는 수동 촬영을 사용합니다.
3. 모서리를 확인하고 내용과 필요한 페이지 경계를 남기되 불필요한 테두리는 자릅니다.
4. **Scan More**로 다음 페이지를 추가합니다.
5. 필요한 페이지를 모두 촬영할 때까지 반복합니다.
6. 원래 종이와 스캔 수를 대조한 다음 **Create PDF**를 선택합니다.
7. 결과를 검토하고 PDF만 저장하거나 서명 추가를 계속합니다.

![페이지 자르기와 Scan More 및 Create PDF를 표시하는 SignDocs.](/mockup/scan-document-to-pdf.png)

이는 종이 페이지를 하나의 PDF로 촬영하는 기능입니다. 기존 PDF 여러 개의 병합이나 OCR 문자 인식을 제공한다는 의미는 아닙니다.

## 메모의 기본 스캐너 사용

메모를 열거나 새로 만들고 첨부 컨트롤에서 문서 스캔을 선택하세요. 종이를 화면에 맞추면 자동 모드는 기기가 촬영하고 수동 모드는 직접 촬영한 뒤 모서리를 조정합니다.

세션을 끝내기 전에 나머지 페이지도 추가하세요. 현재 컨트롤은 링크한 Apple 설명을 확인합니다. 독립된 PDF로 보내려면 결과 첨부 파일과 해당 OS 버전에 맞는 저장·공유 옵션을 확인하세요.

## 보내기 전 검토

모든 페이지를 읽을 수 있는 크기로 보세요. 가장자리에서 잘린 글씨, 서명란의 반사, 흐림과 중복 페이지를 찾습니다. 모든 테두리가 똑같이 보이는 것보다 내용의 가독성이 중요합니다.

쓸 수 없는 페이지는 최종 PDF에 의존하기 전에 고치세요. 원근 보정은 이미지를 반듯하게 만들 수 있지만 손가락에 가려졌거나 사진 밖에서 잘린 글씨를 복구하지는 못합니다.
