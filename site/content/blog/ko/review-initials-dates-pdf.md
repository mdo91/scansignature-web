SignDocs에서 손글씨 이니셜이나 서명을 선택하고 필요한 날짜를 추가한 다음, 페이지마다 배치를 확인하세요. 완성본은 별도의 평면화된 PDF 사본으로 저장합니다. 추가한 항목은 이동, 크기 조절, 복제가 가능하며 작업 중 변경 사항을 실행 취소하거나 다시 실행할 수 있습니다. 페이지 간 복제는 페이지의 크기와 방향 등 기하 구조가 맞아야 합니다. 맞지 않는 페이지에는 직접 배치하세요.

## 먼저 필요한 위치를 정리하기

파일 앱에서 PDF를 열고 문서 이름과 페이지 수를 확인합니다. 클라우드에만 있는 파일은 연결되어 있을 때 내려받으세요. 문서의 지시를 읽고 어느 페이지에 이니셜, 전체 서명, 날짜가 필요한지 따로 적어 둡니다. 모든 페이지에 같은 표시가 필요하다고 가정하지 마세요. 내용이 바뀐 문서인지도 먼저 확인해야 이전 문서의 배치 습관을 그대로 적용하는 일을 피할 수 있습니다.

로컬 라이브러리에서 이 문서에 쓸 손글씨를 고릅니다. 이니셜과 전체 서명은 별도로 선택할 대상입니다. 필요한 이니셜이 없다면 종이에 직접 써서 촬영합니다. Clean, Balanced, Bold 결과를 비교할 때는 가는 획이 남아 있는지 살펴보세요. 준비 과정은 [손글씨 촬영 안내](/ko/blog/scan-handwritten-signature-iphone/)에서 확인할 수 있습니다.

## 페이지마다 배치하고 확인하기

1. 이니셜이 필요한 첫 페이지를 선택합니다. 원하는 손글씨를 고른 뒤 인쇄된 문장을 가리지 않도록 위치와 크기를 조절합니다.
2. 날짜가 요구되는 곳에 날짜를 추가합니다. 위치가 맞는지만 보지 말고 날짜 값과 문서가 요구하는 표기 순서를 다시 읽습니다.
3. 다른 페이지로 복제하려면 페이지 기하 구조가 맞아야 합니다. 복제가 가능해도 목적지의 인쇄된 줄을 확인하세요. 같은 크기의 페이지라도 기입란은 다른 위치에 있을 수 있습니다.
4. 크기나 방향이 다른 페이지에는 항목을 직접 배치합니다. 주변 문장과 비교하면서 읽을 수 있는 크기인지 확인합니다.
5. 잘못된 작업은 세션의 실행 취소나 다시 실행으로 수정합니다. 수정한 뒤에는 원치 않는 배치가 하나 더 남아 있지 않은지 해당 페이지를 다시 확인합니다.
6. 처음 적어 둔 목록을 끝까지 확인하고 별도의 완성 사본을 저장합니다. Recent Docs에서 다시 열어 실제 저장된 결과를 검토한 후 공유합니다.

## 세 페이지 문서 확인 예시

첫째와 둘째 페이지에는 이니셜이, 셋째 페이지에는 전체 서명과 날짜가 필요하다고 가정해 보세요. 두 이니셜 위치를 각각 확인합니다. 마지막 페이지가 가로 방향이면 앞 페이지의 위치가 맞을 것으로 생각하지 말고 직접 서명을 배치하세요. 저장한 PDF와 목록을 대조하여 이니셜 두 개, 전체 서명 한 개, 필요한 날짜가 있는지 셉니다. 불필요한 중복도 확인하세요. 이 예시는 실제 문서의 요구 사항을 대신하지 않습니다.

## 기본 도구와 제한 사항

iOS 26의 Apple 미리보기에서도 PDF에 서명을 추가할 수 있습니다. [Apple의 안내](https://support.apple.com/guide/iphone/fill-out-and-sign-pdf-forms-iphd7e3c0c74/26/ios/26)로 충분하다면 추가 설치가 필요하지 않습니다. 종이에 쓴 손글씨를 촬영하고 여러 이니셜, 서명, 날짜를 한 문서에서 배치하려는 경우 SignDocs가 유용합니다.

SignDocs는 iOS/iPadOS 26 이상이 필요하고 무료 내보내기는 제한됩니다. 처리는 기기에서 이루어지며 처리를 위한 계정이나 문서 업로드가 필요하지 않습니다. 설치, 구매 및 복원, 클라우드 파일 가져오기, 외부 전송에는 각각 연결 조건이 있습니다. 손글씨는 이미지이며 인증서 서명이나 신원 확인이 아닙니다. 출력은 평면화되므로 서명 전 원본을 보관하세요. [저장과 공유 안내](/ko/blog/save-share-signed-pdf-iphone/)에 따라 실제 첨부 파일도 확인합니다.
