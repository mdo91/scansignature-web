SignDocs에서 Saved form 또는 Layout only로 재사용할 배치를 준비하고 사용 전에 미리보기를 확인하세요. 템플릿을 저장하면 입력 내용, 날짜와 손글씨가 지워집니다. 서명과 이니셜에 사용할 손글씨는 매번 다시 선택합니다. 다만 원본 PDF에 이미 인쇄되었거나 평면화된 정보는 그대로 남습니다.

## 무엇을 보관할지 선택하기

**Saved form**은 보호된 로컬 PDF 사본과 배치를 함께 보관합니다. 같은 빈 양식을 다시 쓸 때 적합합니다. 먼저 원본을 확인하세요. 이전 참가자의 이름이 이미 페이지에 합쳐져 있다면 새 입력이 지워져도 그 이름은 남습니다.

**Layout only**는 PDF 내용 없이 위치와 필드 정의를 보관합니다. 재사용할 때 호환되는 PDF를 제공해야 합니다. 적용하기 전에 문서 버전, 페이지 구성과 답변 위치를 비교하세요. 파일 이름이 비슷하다는 이유만으로 호환된다고 판단하면 안 됩니다.

## 준비하고 다시 사용하는 순서

1. 빈 원본을 따로 보관합니다. 클라우드에만 있다면 연결되어 있을 때 내려받은 뒤 파일 앱에서 SignDocs로 엽니다.
2. 모든 페이지를 읽고 이전 답변이 페이지 자체에 포함되어 있는지 확인합니다. 남아 있다면 빈 원본을 구하세요. 템플릿은 이미 있는 내용을 지우는 도구가 아닙니다.
3. 반복 작업에 필요한 배치를 준비합니다. PDF와 배치를 모두 보관하려면 Saved form, PDF 내용 없이 배치만 보관하려면 Layout only를 선택합니다.
4. 템플릿을 저장합니다. 입력한 텍스트, 선택 항목, 날짜와 손글씨가 지워집니다. 서명과 이니셜 위치에는 손글씨를 새로 선택해야 합니다.
5. 재사용 전에 미리보기를 확인합니다. Layout only에는 호환되는 PDF를 제공하고 위치가 실제 질문과 빈칸에 맞는지 하나씩 비교합니다.
6. 이번 문서의 답변과 날짜를 입력하고 손글씨를 다시 선택합니다. 모든 페이지를 검토한 후 별도의 평면화된 PDF를 저장합니다. Recent Docs에서 다시 열어 실제 결과를 확인한 다음 공유하세요.

## 매주 쓰는 준비물 신청서 확인하기

워크숍이 같은 준비물 신청서를 매주 사용한다고 가정해 보세요. 지난주 완성본 대신 빈 양식에서 시작합니다. 재사용 미리보기에서 참가자 이름, 시간대 선택과 서명 위치를 확인하세요. 새 입력은 비어 있어야 하지만 원본에 이미 평면화된 이름은 Saved form에 계속 보입니다. 새 답변이 지워졌다는 사실만 보고 인쇄된 부분까지 비었다고 생각하면 안 됩니다.

주최자가 양식을 바꿔 준비물 질문을 옮겼다면 예전 배치가 그대로 맞는지 확인해야 합니다. 입력하기 전에 각 위치를 새 페이지와 대조하세요. 긴 답변을 입력한 뒤에는 마지막 줄의 끝까지 읽습니다. 재사용하는 위치라도 매번 다른 길이의 답변이 모두 들어간다는 보장은 없습니다. 글자가 다음 질문을 가리지 않는지도 전체 페이지 크기에서 확인합니다.

## 기본 기능과 제한

한 번만 작성하는 문서라면 [iOS 26의 Apple 미리보기](https://support.apple.com/guide/iphone/fill-out-and-sign-pdf-forms-iphd7e3c0c74/26/ios/26)로 충분할 수 있습니다. PDF를 열고 양식 입력 기능과 필드를 선택해 키보드로 입력합니다. 별도 설치가 필수는 아닙니다. 로컬 배치를 반복해서 쓰면서 종이에서 촬영한 손글씨를 [양식 작성](/ko/blog/fill-pdf-form-iphone/)과 함께 사용하려면 SignDocs가 도움이 됩니다.

SignDocs는 iOS/iPadOS 26 이상이 필요하며 무료 내보내기는 제한됩니다. 처리와 템플릿 저장은 기기 안에서 이루어지며 처리용 문서 업로드나 계정이 필요하지 않습니다. 설치, 구매와 복원, 클라우드 가져오기 및 외부 공유에는 각각 연결 조건이 있습니다. 템플릿은 인쇄된 개인정보를 가리거나 서명을 자동 적용하지 않습니다. 완성본은 별도의 평면화된 PDF이며 내보낸 필드가 계속 대화형으로 작동한다고 기대하면 안 됩니다. 빈 원본과 템플릿을 보관하고 [저장 및 공유 안내](/ko/blog/save-share-signed-pdf-iphone/)로 실제 첨부 파일을 확인하세요.
