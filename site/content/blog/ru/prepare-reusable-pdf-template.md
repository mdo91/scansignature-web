В SignDocs подготовьте многоразовый макет в режиме Saved form или Layout only и проверьте предварительный просмотр перед повторным использованием. При сохранении шаблона введённые значения, даты и рукопись очищаются. Для каждого документа выбирайте рукопись заново. Уже напечатанные или сведённые в страницу PDF сведения при этом остаются.

## Что сохраняют два режима

**Saved form** хранит защищённую локальную копию PDF вместе с макетом. Он подходит для повторной работы с одним пустым бланком. Сначала проверьте источник: имя, уже включённое в содержимое страницы, останется даже после очистки новых записей.

**Layout only** хранит позиции и определения полей без содержимого PDF. Для повторного использования нужен совместимый PDF. Сравните версию, порядок страниц и места для ответов до применения макета. Похожее имя файла само по себе не подтверждает совместимость.

## Подготовка и повторное использование

1. Сохраните пустой оригинал. Если он только в облаке, загрузите его при наличии соединения, затем откройте из «Файлов» в SignDocs.
2. Просмотрите каждую страницу: нет ли старых ответов, уже ставших её частью? При необходимости получите пустой источник. Шаблон не удаляет эти сведения.
3. Подготовьте макет для повторяющейся задачи. Выберите Saved form для PDF и макета либо Layout only для макета без содержимого PDF.
4. Сохраните шаблон. Текстовые записи, варианты выбора, даты и рукопись очищаются. Для позиций подписи и инициалов потребуется заново выбрать рукопись.
5. Проверьте предварительный просмотр перед применением. Для Layout only предоставьте совместимый PDF и сравните позиции с его реальными вопросами и пустыми местами.
6. Введите ответы и даты для текущего документа, заново выберите рукопись и проверьте все страницы. Сохраните отдельную сведённую готовую PDF-копию и откройте её из Recent Docs перед отправкой.

## Пример еженедельной заявки на оборудование

Представьте мастерскую, которая каждую неделю использует одинаковую заявку на оборудование. Начните с пустого бланка, а не с готового PDF прошлой недели. В предварительном просмотре проверьте строку участника, выбор времени и область подписи. Новые записи должны быть пустыми, однако имя, уже сведённое в исходную страницу, останется видно в Saved form.

Если организатор перенёс вопрос об оборудовании, не считайте прежний макет подходящим автоматически. Сравните каждую позицию с обновлённой страницей до ввода ответов. После заполнения прочитайте конец последней строки длинного ответа. Возможность повторно использовать позицию не означает, что любой новый текст поместится в отведённом месте.

## Встроенная альтернатива и ограничения

Для одного бланка может хватить [«Просмотра» Apple в iOS 26](https://support.apple.com/guide/iphone/fill-out-and-sign-pdf-forms-iphd7e3c0c74/26/ios/26): откройте PDF, выберите заполнение формы, поле и введите текст. Установка другого приложения необязательна. SignDocs полезен для сочетания локальных многоразовых макетов и рукописи с бумаги с [заполнением форм](/ru/blog/fill-pdf-form-iphone/).

SignDocs требует iOS/iPadOS 26 или новее. Обработка и хранение шаблонов происходят на устройстве без аккаунта и загрузки документов для обработки. Установка, покупки/восстановление, получение облачных файлов и внешняя отправка имеют отдельные требования к соединению. Бесплатные экспорты ограничены. Шаблоны не скрывают напечатанные персональные сведения и не применяют подпись автоматически. Результат — отдельный сведённый PDF; не рассчитывайте на интерактивность экспортированных полей. Храните пустой источник и шаблон. Проверьте фактическое вложение по [руководству по сохранению и отправке](/ru/blog/save-share-signed-pdf-iphone/).
