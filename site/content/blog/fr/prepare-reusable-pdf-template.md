Dans SignDocs, préparez un modèle avec Saved form ou Layout only, puis examinez son aperçu avant de le réutiliser. Les saisies, dates et écritures sont effacées lors de l’enregistrement du modèle. Il faut choisir de nouveau l’écriture. En revanche, les informations déjà imprimées ou aplaties dans le PDF restent présentes.

## Choisir ce qui sera conservé

**Saved form** conserve une copie locale protégée du PDF et sa disposition. Ce mode convient pour reprendre le même formulaire vierge. Vérifiez le fichier de départ : un nom déjà intégré à la page restera visible même si les nouvelles saisies sont effacées.

**Layout only** conserve les positions et définitions de champs, sans le contenu du PDF. Il faut fournir un PDF compatible pour réutiliser cette disposition. Comparez la version du document, ses pages et les espaces de réponse. Un nom de fichier ressemblant ne suffit pas à confirmer la compatibilité.

## Préparer puis réutiliser

1. Conservez un original vierge. Téléchargez-le pendant que vous êtes connecté s’il est uniquement dans le cloud, puis ouvrez-le depuis Fichiers dans SignDocs.
2. Inspectez chaque page pour repérer les anciennes réponses déjà intégrées au PDF. Demandez une version vierge si nécessaire : le modèle ne sert pas à les supprimer.
3. Préparez la disposition utile, puis choisissez Saved form pour conserver aussi le PDF, ou Layout only pour garder uniquement la disposition.
4. Enregistrez le modèle. Texte saisi, choix, dates et écritures sont effacés. Les emplacements de signature et de paraphe nécessitent une nouvelle sélection d’écriture.
5. Examinez l’aperçu avant réutilisation. Avec Layout only, fournissez le PDF compatible et comparez chaque emplacement avec la question correspondante.
6. Saisissez les réponses et dates du nouveau document. Choisissez l’écriture, contrôlez toutes les pages, puis enregistrez une copie terminée aplatie. Rouvrez-la dans Recent Docs avant l’envoi.

## Exemple : une fiche de matériel récurrente

Pour une fiche d’atelier hebdomadaire, partez du formulaire vierge, pas du PDF rempli la semaine précédente. Vérifiez dans l’aperçu la ligne du participant, le choix de séance et la zone de signature. Les nouvelles saisies doivent être vides ; un ancien nom aplati dans le fichier source resterait pourtant présent dans Saved form.

Si l’organisateur déplace la question sur le matériel, comparez la nouvelle page avec la disposition avant de remplir. Après saisie, relisez la dernière ligne des réponses longues : un emplacement réutilisable ne garantit pas que chaque réponse future tiendra dedans.

## Autre option et limites

Pour un seul document, [Aperçu sous iOS 26](https://support.apple.com/guide/iphone/fill-out-and-sign-pdf-forms-iphd7e3c0c74/26/ios/26) peut suffire. Ouvrez le PDF, sélectionnez la fonction de remplissage puis un champ et saisissez au clavier. Une installation supplémentaire est facultative. SignDocs convient pour associer modèles locaux et écriture capturée sur papier au [remplissage des formulaires](/fr/blog/fill-pdf-form-iphone/).

SignDocs nécessite iOS/iPadOS 26 ou ultérieur. Le traitement et les modèles restent sur l’appareil, sans compte ni téléversement pour le traitement. Installation, achats/restauration, récupération cloud et partage externe ont leurs propres besoins de connexion. Les exports gratuits sont limités. Les modèles ne caviardent pas le contenu imprimé et n’appliquent pas automatiquement une signature. Le résultat est une copie PDF aplatie, sans promesse de champs encore modifiables. Conservez l’original vierge et vérifiez le fichier avec le [guide d’enregistrement et de partage](/fr/blog/save-share-signed-pdf-iphone/).
