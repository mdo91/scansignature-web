In SignDocs, prepare a reusable layout with Saved form or Layout only, then preview it before reuse. Entries, dates and handwriting are cleared when the template is saved; choose handwriting again for each document. This does not remove information already printed or flattened into the PDF.

## Choose what the template keeps

**Saved form** keeps a protected local PDF copy together with its layout. Use it when the same blank source form is needed again. Check the source first: an earlier participant’s name printed into the page will remain, even though new entries are cleared.

**Layout only** keeps positions and field definitions without storing the PDF content. You must supply a compatible PDF when reusing it. Compare the version, page arrangement and answer locations before applying the layout. A similar filename alone does not establish compatibility.

## Prepare and reuse deliberately

1. Keep a blank original. If it exists only in cloud storage, retrieve it while connected, then open it from Files in SignDocs.
2. Inspect every page for old answers already incorporated into the page. If those remain, obtain a blank source rather than treating a template as a way to erase them.
3. Prepare the needed layout for the recurring task. Choose Saved form to retain the PDF and layout, or Layout only to retain the layout without PDF content.
4. Save the template. Text entries, choices, dates and handwriting are cleared; signature and initials positions need a fresh handwriting selection.
5. Preview before reuse. For Layout only, provide the compatible PDF and compare the positions with its actual questions and blank spaces.
6. Enter this document’s answers and dates, select the intended handwriting again, and review all pages. Save a separate flattened completed PDF and reopen the result from Recent Docs before sharing.

## Check a recurring workshop form

Suppose a workshop uses the same equipment request each week. Start with its blank form, not last week’s completed PDF. In the reuse preview, inspect the participant line, session choice and signature area. New entries should be blank, but a participant name already flattened into the source would still be visible in Saved form.

If the workshop changes the form and moves the equipment question, do not assume the old layout still fits. Compare each position with the revised page before entering answers. Check the last line of a multiline answer after filling; a reusable position does not guarantee that every future answer will fit.

## Alternatives and limits

For a single form, [Apple’s iOS 26 Preview instructions](https://support.apple.com/guide/iphone/fill-out-and-sign-pdf-forms-iphd7e3c0c74/26/ios/26) may be enough: open the PDF, select Form Filling, select a field and type. Another installation is optional. SignDocs is useful when you want local reusable layouts and paper-captured handwriting alongside [form filling](/blog/fill-pdf-form-iphone/).

SignDocs requires iOS/iPadOS 26 or later. Processing and template storage stay on device without an account or document upload for processing. Installation, purchases/restores, cloud retrieval and external sharing have separate connection requirements. Free completed exports are limited. Templates do not redact printed information or apply a signature automatically. Completed exports are flattened copies, not reusable interactive fields; keep the blank source and template. Follow the [save and share checklist](/blog/save-share-signed-pdf-iphone/) for the exact attachment.
